# Security Policy

## Supported Versions

Security updates are provided for the latest version on the default branch. Older versions may not receive security fixes. Upgrade to the latest version where possible.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately using GitHub's **Report a vulnerability** option in the repository's **Security** tab. Do not report security issues through public issues, discussions, or pull requests.

When reporting, include as much of the following as possible:

- A description of the issue and its potential impact
- Steps to reproduce or a proof of concept
- Affected versions, configurations, and components
- Any suggested mitigation

We aim to acknowledge reports within 5 business days and will provide updates as we investigate. We will coordinate remediation and public disclosure with the reporter. Please allow maintainers a reasonable opportunity to address the issue before disclosing it publicly.

If private vulnerability reporting is unavailable, contact a repository maintainer directly to arrange a secure reporting channel.
